電腦開不了機怎麼辦？5 個自己能做的檢查

症狀：按了電源鍵完全沒反應、燈不亮；或是風扇有轉、燈有亮，但螢幕一片黑。先分清楚是「完全沒電」還是「有電沒畫面」，照下面順序查：

  1. 1. 確認電源真的有進來。插座換一個試試、延長線開關有沒有被踢掉、電源線有沒有插緊（主機後面那條最常鬆）。筆電的話，先插著充電器等 10 分鐘再開機，電池完全沒電時不會馬上有反應。
  2. 2. 確認螢幕是醒著的。螢幕電源燈有亮嗎？訊號來源（HDMI／DP）有沒有選對？螢幕線兩端重插一次，這一步救回的人比你想的多。
  3. 3. 拔掉所有外接裝置。USB 隨身碟、外接硬碟、讀卡機、印表機線全部拔掉，只留電源、螢幕、鍵盤滑鼠，再開機一次。壞掉的外接裝置會卡住開機流程。
  4. 4. 長按電源鍵強制重開。按住電源鍵 10 秒讓它完全斷電，等 30 秒再按一次開機。筆電如果是可拆電池，先拔電池、用充電器直接開機試試。
  5. 5. 聽聲音、看燈號。開機時有沒有「嗶」聲？主機板燈有沒有亮？風扇是轉一下就停、還是持續轉？把這些現象記下來，就算最後要送修，也能幫師傅省很多診斷時間。

出現這些情況，就別再試了

  • 聞到燒焦味、看到冒煙，或電源供應器有異音、火花
  • 機器進水、倒了飲料
  • 反覆開機都自動斷電，還伴隨「喀喀」異音
  • 想自己打開機殼摸電源供應器——絕對不要，電源供應器內部有殘存高壓，非專業人員不要拆，交給我們處理

還是開不了機？
把主機燈號、螢幕畫面拍下來傳 LINE，我們看照片就能先判斷大概是哪裡壞、修起來多少錢。

電腦變慢、卡頓？先做這 6 個自救動作

症狀：開機要等很久、開程式轉圈圈、滑鼠會頓、風扇一直狂轉。變慢通常不是壞掉，而是太操勞或太久沒整理：

  1. 1. 先重開機，不是關螢幕。很多人一個月沒真正重開過。從開始選單選「重新啟動」，讓系統把卡住的東西清乾淨。
  2. 2. 看誰在吃效能。按 Ctrl+Shift+Esc 開「工作管理員」，看 CPU、記憶體、磁碟哪個衝到 90% 以上，排第一名的程式就是兇手，先把它關掉。
  3. 3. 清出硬碟空間。C 槽至少留 15% 空間。桌面、下載資料夾最容易塞爆，先把大檔案搬到外接硬碟或雲端。
  4. 4. 關掉開機自動啟動。工作管理員→「啟動」分頁，把用不到的程式改成「已停用」，開機速度會差很多。
  5. 5. 掃一次毒。用 Windows 內建的「Windows 安全性」跑完整掃描。瀏覽器如果一直跳廣告、首頁被換掉，多半中了廣告程式。
  6. 6. 摸摸看是不是太熱。筆電出風口是不是燙手、風扇是不是一直全速？散熱孔清灰塵、墊高機身通風。桌機用了好幾年沒清過，散熱膏乾掉也會讓它熱到降速——這部分建議交給我們處理，不要自己拆散熱器。

出現這些情況，就別再硬撐了

  • 硬碟發出「喀喀」規律異音——先立刻備份重要檔案，不要再反覆開關機操它
  • 用了 5 年以上的傳統硬碟（HDD）還沒換 SSD，慢多半是硬碟老化
  • 掃毒掃出東西卻清不掉，或檔案莫名被加密（勒索病毒前兆）——先拔網路線再找我們

做完還是慢？
老電腦換 SSD、加記憶體通常就能回春。拍下你的電腦型號傳 LINE，我們幫你看升級划不划算，不換新也沒關係。

網路、Wi-Fi 突然斷線？照順序這樣排除

症狀：Wi-Fi 圖示出現驚嘆號、連得上但沒網路、只有某一台裝置上不了網。網路問題最忌亂按，照順序來：

  1. 1. 先確認範圍。手機、其他電腦也斷嗎？只有一台斷→問題在那台；全部都斷→問題在分享器或電信業者。
  2. 2. 正確重開網路設備。把數據機和 Wi-Fi 分享器的電源都拔掉，等 30 秒，先插數據機、等燈號穩定（約 2 分鐘），再插分享器。順序錯了常常白重開。
  3. 3. 看燈號。數據機如果亮紅燈、或該亮的燈沒亮，先拍照記下來，這通常是線路或業者端問題。
  4. 4. 只有一台不行時。把那台的 Wi-Fi 關掉重開；再不行就「忘記這個網路」重新連、重新打密碼。筆電也確認沒有誤開飛航模式。
  5. 5. 換個方式連連看。桌機改插網路線測試、手機靠近分享器測試。如果插線正常、Wi-Fi 不行，多半是分享器老化或訊號被遮擋。
  6. 6. 查業者公告。中華電信、凱擘等業者網站或粉專會公告區域障礙與施工，颱風大雨後特別常見，全區障礙就只能等修復。

出現這些情況，就別再自己試了

  • 分享器用了 5 年以上、重開後撐不久又斷——多半是設備老化，換新比一直重開划算
  • 數據機燈號異常且業者說線路正常，可能是屋內線路或設備故障
  • 全家裝置都連得上、速度卻慢到異常，先確認是不是有人在大量下載，或帳單、方案被限速

搞不清楚是哪一段壞？
把數據機、分享器的燈號拍下來傳 LINE，我們看燈號就能先判斷是線路、設備還是設定問題。

藍屏、當機一直重開？初步判斷這樣做

症狀：用到一半跳藍色畫面（藍屏）、畫面凍結滑鼠不動、或自己重新開機。藍屏不是世界末日，它其實是電腦在告訴你哪裡出問題：

  1. 1. 把藍屏拍下來。藍屏下方有一串錯誤代碼（例如 MEMORY_MANAGEMENT、IRQL_NOT_LESS_OR_EQUAL），先用手機拍清楚，這是師傅最需要的線索。
  2. 2. 回想最近改了什麼。藍屏前有沒有裝新軟體、更新驅動程式、加新硬體、或 Windows 剛更新完？十之八九跟最近的變動有關，先記下來。
  3. 3. 先拔外接裝置再開機。外接硬碟、USB 裝置先全拔，只留鍵盤滑鼠螢幕，能正常進桌面就逐一插回找兇手。
  4. 4. 注意溫度與灰塵。當機都發生在打遊戲、剪影片這種高負載時？機身是不是很燙、風扇很吵？過熱保護也會造成當機重開，這種多半清灰塵、換散熱膏能改善（拆機清潔建議交給我們）。
  5. 5. 資料重要先備份。如果還能進桌面，第一件事是把重要檔案備份到外接硬碟或雲端，再慢慢查。不要在這種狀態下直接重灌，資料會先不見。

出現這些情況，就別再自己試了

  • 藍屏越來越頻繁，從偶爾變成每天、甚至開機就藍
  • 伴隨硬碟異音、檔案莫名損壞或消失——硬碟可能快壞了，先停手保資料
  • 自己完全沒動任何設定就突然開始當機，多半是硬體（記憶體、硬碟、電源）出問題，需要檢測儀器判斷，不要自行拆記憶體或電源供應器測試
