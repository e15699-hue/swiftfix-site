電腦開不了機怎麼辦？5 個自己能做的檢查

症狀：按了電源鍵完全沒反應、燈不亮；或是風扇有轉、燈有亮，但螢幕一片黑。先分清楚是「完全沒電」還是「有電沒畫面」，照下面順序查：

  1. 1. 確認電源真的有進來。插座換一個試試、延長線開關有沒有被踢掉、電源線有沒有插緊（主機後面那條最常鬆）。筆電的話，先插著充電器等 10 分鐘再開機，電池完全沒電時不會馬上有反應。
  2. 2. 確認螢幕是醒著的。螢幕電源燈有亮嗎？訊號來源（HDMI／DP）有沒有選對？螢幕線兩端重插一次，這一步救回的人比你想的多。
  3. 3. 拔掉所有外接裝置。USB 隨身碟、外接硬碟、讀卡機、印表機線全部拔掉，只留電源、螢幕、鍵盤滑鼠，再開機一次。壞掉的外接裝置會卡住開機流程。
  4. 4. 長按電源鍵強制重開。按住電源鍵 10 秒讓它完全斷電，等 30 秒再按一次開機。筆電如果是可拆電池，先拔電池、用充電器直接開機試試。
  5. 5. 聽聲音、看燈號。開機時有沒有「嗶」聲？主機板燈有沒有亮？風扇是轉一下就停、還是持續轉？把這些現象記下來，就算最後要送修，也能幫師傅省很多診斷時間。

出現這些情況，就別再試了

  • 聞到燒焦味、看到冒煙，或電源供應器有異音、火花
  • 機器進水、倒了飲料
  • 反覆開機都自動斷電，還伴隨「喀喀」異音
  • 想自己打開機殼摸電源供應器——絕對不要，電源供應器內部有殘存高壓，非專業人員不要拆，交給我們處理

還是開不了機？
把主機燈號、螢幕畫面拍下來傳 LINE，我們看照片就能先判斷大概是哪裡壞、修起來多少錢。

電腦變慢、卡頓？先做這 6 個自救動作

症狀：開機要等很久、開程式轉圈圈、滑鼠會頓、風扇一直狂轉。變慢通常不是壞掉，而是太操勞或太久沒整理：

  1. 1. 先重開機，不是關螢幕。很多人一個月沒真正重開過。從開始選單選「重新啟動」，讓系統把卡住的東西清乾淨。
  2. 2. 看誰在吃效能。按 Ctrl+Shift+Esc 開「工作管理員」，看 CPU、記憶體、磁碟哪個衝到 90% 以上，排第一名的程式就是兇手，先把它關掉。
  3. 3. 清出硬碟空間。C 槽至少留 15% 空間。桌面、下載資料夾最容易塞爆，先把大檔案搬到外接硬碟或雲端。
  4. 4. 關掉開機自動啟動。工作管理員→「啟動」分頁，把用不到的程式改成「已停用」，開機速度會差很多。
  5. 5. 掃一次毒。用 Windows 內建的「Windows 安全性」跑完整掃描。瀏覽器如果一直跳廣告、首頁被換掉，多半中了廣告程式。
  6. 6. 摸摸看是不是太熱。筆電出風口是不是燙手、風扇是不是一直全速？散熱孔清灰塵、墊高機身通風。桌機用了好幾年沒清過，散熱膏乾掉也會讓它熱到降速——這部分建議交給我們處理，不要自己拆散熱器。

出現這些情況，就別再硬撐了

  • 硬碟發出「喀喀」規律異音——先立刻備份重要檔案，不要再反覆開關機操它
  • 用了 5 年以上的傳統硬碟（HDD）還沒換 SSD，慢多半是硬碟老化
  • 掃毒掃出東西卻清不掉，或檔案莫名被加密（勒索病毒前兆）——先拔網路線再找我們

做完還是慢？
老電腦換 SSD、加記憶體通常就能回春。拍下你的電腦型號傳 LINE，我們幫你看升級划不划算，不換新也沒關係。

網路、Wi-Fi 突然斷線？照順序這樣排除

症狀：Wi-Fi 圖示出現驚嘆號、連得上但沒網路、只有某一台裝置上不了網。網路問題最忌亂按，照順序來：

  1. 1. 先確認範圍。手機、其他電腦也斷嗎？只有一台斷→問題在那台；全部都斷→問題在分享器或電信業者。
  2. 2. 正確重開網路設備。把數據機和 Wi-Fi 分享器的電源都拔掉，等 30 秒，先插數據機、等燈號穩定（約 2 分鐘），再插分享器。順序錯了常常白重開。
  3. 3. 看燈號。數據機如果亮紅燈、或該亮的燈沒亮，先拍照記下來，這通常是線路或業者端問題。
  4. 4. 只有一台不行時。把那台的 Wi-Fi 關掉重開；再不行就「忘記這個網路」重新連、重新打密碼。筆電也確認沒有誤開飛航模式。
  5. 5. 換個方式連連看。桌機改插網路線測試、手機靠近分享器測試。如果插線正常、Wi-Fi 不行，多半是分享器老化或訊號被遮擋。
  6. 6. 查業者公告。中華電信、凱擘等業者網站或粉專會公告區域障礙與施工，颱風大雨後特別常見，全區障礙就只能等修復。

出現這些情況，就別再自己試了

  • 分享器用了 5 年以上、重開後撐不久又斷——多半是設備老化，換新比一直重開划算
  • 數據機燈號異常且業者說線路正常，可能是屋內線路或設備故障
  • 全家裝置都連得上、速度卻慢到異常，先確認是不是有人在大量下載，或帳單、方案被限速

搞不清楚是哪一段壞？
把數據機、分享器的燈號拍下來傳 LINE，我們看燈號就能先判斷是線路、設備還是設定問題。

藍屏、當機一直重開？初步判斷這樣做

症狀：用到一半跳藍色畫面（藍屏）、畫面凍結滑鼠不動、或自己重新開機。藍屏不是世界末日，它其實是電腦在告訴你哪裡出問題：

  1. 1. 把藍屏拍下來。藍屏下方有一串錯誤代碼（例如 MEMORY_MANAGEMENT、IRQL_NOT_LESS_OR_EQUAL），先用手機拍清楚，這是師傅最需要的線索。
  2. 2. 回想最近改了什麼。藍屏前有沒有裝新軟體、更新驅動程式、加新硬體、或 Windows 剛更新完？十之八九跟最近的變動有關，先記下來。
  3. 3. 先拔外接裝置再開機。外接硬碟、USB 裝置先全拔，只留鍵盤滑鼠螢幕，能正常進桌面就逐一插回找兇手。
  4. 4. 注意溫度與灰塵。當機都發生在打遊戲、剪影片這種高負載時？機身是不是很燙、風扇很吵？過熱保護也會造成當機重開，這種多半清灰塵、換散熱膏能改善（拆機清潔建議交給我們）。
  5. 5. 資料重要先備份。如果還能進桌面，第一件事是把重要檔案備份到外接硬碟或雲端，再慢慢查。不要在這種狀態下直接重灌，資料會先不見。

出現這些情況，就別再自己試了

  • 藍屏越來越頻繁，從偶爾變成每天、甚至開機就藍
  • 伴隨硬碟異音、檔案莫名損壞或消失——硬碟可能快壞了，先停手保資料
  • 自己完全沒動任何設定就突然開始當機，多半是硬體（記憶體、硬碟、電源）出問題，需要檢測儀器判斷，不要自行拆記憶體或電源供應器測試

藍屏照片拍好了？
直接傳 LINE 給我們，錯誤代碼一看就知道往哪個方向查，先免費評估、報價透明，確認後再預約維修。

筆電完全沒反應、開不了機？先做放電重置

症狀：筆電按電源鍵完全沒反應、燈不亮，昨天還好好的今天就開不起來。筆電有一招最有名的自救動作，先做這套「放電重置」，很多假故障一次就好：

  1. 1. 先插著充電器等 10 分鐘。電池完全放到乾的筆電，插上充電器不會馬上有反應。先插著等 10 分鐘（順便看充電燈有沒有亮），再按一次電源鍵。
  2. 2. 長按電源鍵 40 秒（放電重置）。把充電器和所有外接（滑鼠、隨身碟、HDMI 線）都拔掉，按住電源鍵整整 40 秒不要放（心裡慢慢數），放開後插回充電器，再按電源鍵開機。主機板殘留的靜電和當掉的電源管理晶片，常常靠這招就醒了。
  3. 3. 檢查充電燈和充電器。充電燈完全不亮的話，換一個插座試試；充電線有沒有被椅子壓傷、變壓器有沒有發燙或異味。家裡如果有同廠牌的充電器，可以交叉測一下。
  4. 4. 可拆電池的機型，拔電池試試。電池能拆的舊款筆電：先拔掉電池，只插充電器開機看看。能開就是電池壞了，換電池就好。
  5. 5. 拔掉所有外接再開一次。壞掉的 USB 裝置、記憶卡也會讓筆電卡住不開機。全部拔光、只留充電器，再開一次。

出現這些情況，就別再自己試了

  • 底殼或觸控板鼓起來、鍵盤面隆起——這是電池膨脹，不要再充電使用，有起火風險，直接找我們處理
  • 筆電進水、倒到飲料——不要開機、不要充電，盡快送來拆機清潔，越拖腐蝕越嚴重
  • 充電孔鬆動、插著會冒火花或聞到燒焦味
  • 放電重置做了兩次還是完全沒反應，多半是主機板或電源迴路故障，需要檢測

放電重置也沒用？
把筆電型號和充電燈的狀態拍下來傳 LINE，我們先幫你判斷是電池、充電器還是主機板的問題，估好價再決定修不修。

開機有聲音、風扇有轉，但螢幕黑畫面？

症狀：電源燈亮、風扇在轉、甚至聽得到開機音效，但螢幕就是一片黑。先別急著送修，很多時候是螢幕沒被「叫醒」而已：

  1. 1. 先按亮度鍵。筆電鍵盤上的亮度「＋」按幾次（通常要配合 Fn 鍵）。亮度被調到最低時，螢幕看起來跟沒開一樣，這一步救回的人超多。
  2. 2. 按 Win+Ctrl+Shift+B。這是 Windows 重啟顯示驅動的快捷鍵，按下去會「嗶」一聲、畫面閃一下。螢幕驅動當掉時，這招常常直接讓畫面回來。
  3. 3. 切換投影模式。按 Win+P，再按方向鍵或連按幾次 Win+P 切換「僅電腦螢幕」。系統有時會誤以為接了第二台螢幕，把畫面送到不存在的螢幕去。筆電也可以試 Fn＋投影鍵（圖示是螢幕的那顆）。
  4. 4. 外接螢幕測看看。用 HDMI 線接電視或另一台螢幕。有畫面→筆電自己的螢幕或排線問題；外接也沒畫面→比較像顯示晶片或主機板問題。這個結果告訴師傅，診斷會快很多。
  5. 5. 蓋上再打開。把筆電蓋上等 30 秒再打開，有時是睡眠喚醒卡住。桌機的話，螢幕訊號線兩端重插、確認訊號來源（HDMI／DP）選對。

出現這些情況，就別再自己試了

  • 螢幕有裂痕、彩色直線、或摔過之後才黑屏——多半是面板受損，要換螢幕
  • 開合螢幕角度不同時畫面閃爍、時好時壞——排線可能快斷了，別再反覆開合硬撐
  • 外接螢幕也沒畫面、還伴隨嗶嗶警報聲——記下嗶聲的次數節奏，告訴師傅

外接也沒畫面？
把黑屏的狀況（燈號、嗶聲、風扇聲）錄一段或拍下來傳 LINE，我們先幫你縮小範圍，判斷是螢幕、排線還是主機板。

電腦沒聲音？喇叭、耳機都沒聲這樣查

症狀：影片、會議、遊戲突然沒聲音。沒聲音十次有八次是「聲音被送錯地方」，照著查通常不用花錢：

  1. 1. 先確認沒被靜音。右下角喇叭圖示看是不是靜音、音量有沒有被關到 0；筆電鍵盤上的靜音鍵（Fn＋喇叭圖示）也確認一下，可能是不小心按到的。
  2. 2. 換輸出裝置（最常見兇手）。點右下角喇叭圖示旁的箭頭，切換輸出裝置：喇叭、耳機、螢幕（HDMI 也會送聲音）都試一次。很多人是聲音跑去沒開的螢幕喇叭了。
  3. 3. 耳機拔掉重插。耳機孔有時會誤判「耳機還插著」，把聲音一直送耳機。拔掉重插幾次，或先拿別副耳機交叉測試。
  4. 4. 藍牙耳機在搶聲音。藍牙耳機連著但放在耳機盒或別的房間，聲音會送去那邊。把藍牙關掉測一次就知道。
  5. 5. 分辨是單一程式還是全部沒聲。只有某個 App 沒聲→看那個 App 自己的音量設定，或到「設定→系統→音效→音量混音程式」看它是不是被個別靜音；全部都沒聲→重開機一次，還不行就跑 Windows 內建的音效疑難排解員。

出現這些情況，就別再自己試了

  • 聲音有持續爆音、雜音、電流聲，換耳機也一樣——音效晶片或主機板可能受損
  • 耳機孔被異物卡住、或插頭斷在裡面——不要自己拿尖物硬挖
  • 重灌驅動、疑難排解都試過還是沒聲，建議帶來檢測

還是沒聲音？
把你的狀況（全部沒聲還是只有某個程式、用喇叭還是耳機）打字或拍照傳 LINE，我們先幫你判斷是不是硬體問題。

USB 讀不到：隨身碟、滑鼠、鍵盤沒反應

症狀：插上去沒反應、或跳出「無法辨識的 USB 裝置」。先用交叉測試分清楚是裝置壞、還是電腦的問題：

  1. 1. 換一個 USB 孔。同一個裝置換插另一個孔（桌機優先插主機後面的孔，前置孔最常接觸不良）；無線滑鼠鍵盤的接收器也一樣，換孔常常就活了。
  2. 2. 交叉測試。把裝置拿去插另一台電腦：別台也讀不到→裝置壞了；別台正常→問題在你這台。反過來，拿另一個正常裝置插你這台，確認孔位是不是好的。
  3. 3. 無線鍵鼠先換電池、重配對。接收器拔起來重插、鍵鼠開關重開一次；藍牙鍵鼠就移除裝置重新配對。這類「沒反應」一半以上只是沒電。
  4. 4. 重開機再插一次。USB 驅動偶爾會當掉，重開機後先插一個裝置測試，不要一次全插回去。
  5. 5. 隨身碟跳「需要格式化」先停手。裡面有重要資料的話，千萬不要按格式化，也不要反覆插拔一直試，先把隨身碟拔下來找我們看，資料救回的機會差很多。

出現這些情況，就別再自己試了

  • 外接硬碟插上後有「喀喀」異音或一直發燙——立刻拔掉，不要再通電測試，硬碟可能正在受損
  • 隨身碟外殼彎曲、接頭鬆動還硬插，可能把孔位也弄壞
  • 所有孔位、所有裝置都讀不到，且重開機無效——可能是主機板 USB 迴路故障

風扇很吵、機身很燙？過熱自救這樣做

症狀：風扇像吹風機一樣狂轉、筆電燙手、桌機熱風一直吹。過熱會讓電腦降速、當機，長期還傷零件，先做這幾步：

  1. 1. 看誰在讓它操勞。按 Ctrl+Shift+Esc 開工作管理員，看 CPU 使用率最高的是誰。Windows 更新、防毒掃描在跑的時候吵是正常的，等它跑完；不認識的程式長期佔用 90% 以上，先關掉它。
  2. 2. 讓它透氣。筆電不要放在床上、沙發、棉被上用（會堵住底部進風口），墊高後方或用散熱墊；桌機確認後方和側邊出風口沒有貼牆、沒被雜物擋住。
  3. 3. 清出風口灰塵。用軟毛刷把出風口、進風口的灰塵刷掉就好（不用拆機）。養寵物的家庭灰塵和毛特別多，清完常常立刻安靜一截。
