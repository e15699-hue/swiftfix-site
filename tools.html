線上檢測工具

全部在你的瀏覽器裡完成，不用下載、不用註冊，不會上傳任何資料，每項大概一分鐘。
測出異常先別急著買新的，把結果傳 LINE，我們幫你判斷是設定問題還是真的壞了。

鍵盤測試

直接按你的實體鍵盤，按到的鍵會亮起來。全部按過一輪，哪顆沒亮、哪顆按一次跳兩次，就是它有問題。也可以同時按住好幾個鍵，看看是不是都有反應（打遊戲常用組合最容易發現）。

    麥克風測試

    按下開始，瀏覽器會跳出授權提示，同意後對著麥克風說話，下面的音量和波形會跟著動。聲音只在你的瀏覽器裡分析，不會錄下來、更不會上傳。

    尚未開始

    最大音量紀錄：0%（正常說話大約會到 40% 以上；一直很低，可能是麥克風被靜音、插錯孔，或會議軟體選錯裝置）

    怎麼弄都沒聲音、或聲音斷斷續續？把你用的耳機麥克風型號和狀況傳 LINE，我們一步一步陪你排除。

    傳 LINE 評估

    視訊鏡頭測試

    按下開始並同意授權，就會看到鏡頭的即時畫面。畫面只顯示在你的瀏覽器裡，不會上傳、也不會被錄下來。有多顆鏡頭時可以切換裝置。

    尚未開始

    鏡頭解析度：—

    小提醒：畫面全黑先確認筆電鏡頭蓋／隱私遮片有沒有打開；會議軟體（Zoom、Meet、Teams）正開著鏡頭時，這裡會搶不到，關掉會議軟體再測。

    鏡頭抓不到、畫面糊掉或顏色怪怪的？把筆電型號和狀況傳 LINE，幫你判斷是驅動、設定還是鏡頭本身壞了。

    傳 LINE 評估

    喇叭測試

    分別在左聲道、右聲道播放測試音。先把音量開到平常聽歌的大小，再一顆一顆按。單邊沒聲音，可能是喇叭單體壞了，也可能只是音量平衡被調偏。

    尚未播放（已播放：無）

    小提醒：三顆都沒聲音，先看右下角音量圖示有沒有被靜音、輸出裝置是不是選到螢幕或耳機；藍牙耳機連著的時候，聲音會跑去耳機那邊。

    單邊沒聲、破音或雜音？筆電喇叭單體可以單換，傳 LINE 告訴我們型號和哪邊有問題，先幫你估價。

    傳 LINE 評估

    螢幕壞點測試

    用純色把整個螢幕填滿，壞點、亮點和背光不均就藏不住了。點一個顏色開始全螢幕，之後每點一下換下一個顏色，Esc 或「離開」結束。白色找壞點（永遠不亮的黑點），黑色找亮點（永遠亮著的彩色點），灰色看背光均不均勻。

    系統資訊偵測

    問維修最常卡在「你電腦是什麼系統、規格多少」——這裡一次整理好，按「複製檢測摘要」，貼到 LINE 給我們就行。資料只在你的瀏覽器產生，不會上傳。
    先講清楚：顯示卡型號大多能直接讀到，但 CPU、主機板、記憶體和硬碟的具體型號，是瀏覽器故意不給網頁讀的（隱私設計，任何網站都一樣）。要那些型號，請用下面的一鍵檢測小程式。

    要具體型號？Windows 一鍵規格檢測

    下載這個小程式、在你的 Windows 電腦上雙擊執行，它只讀取硬體資訊，會產生一份報告在桌面（同時自動複製），內容包括：電腦品牌型號、CPU 完整型號、主機板型號、每一條記憶體的容量與型號、顯示卡型號、每一顆硬碟的型號與健康狀態。把報告貼到 LINE 給我們，規格就一清二楚。

    • ✓ 只讀取、不修改任何東西，不會上傳，報告只產生在你自己的桌面
    • ✓ 不收集序號、不收集個人檔案；程式內容完全公開，懂的人可以先看原始碼再執行
    • ✓ Windows 跳出「Windows 已保護你的電腦」時，點「其他資訊」→「仍要執行」即可（未簽章的小程式都會跳這個畫面）
