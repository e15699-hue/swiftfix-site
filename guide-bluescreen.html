自救百科・藍屏篇

電腦藍屏、一直重開機？
先拍照，再照順序判斷

藍屏是電腦在保護自己，畫面上的錯誤代碼就是線索。照本文先把代碼和資料顧好，真的排除不了，再拍照傳 LINE 給我們，免費幫您評估。

首頁 ＞ 電腦自救小百科 ＞ 電腦藍屏・自動重開機

用到一半突然跳出藍色畫面、還自己重新開機，確實很嚇人。但請先放心：藍屏（BSOD）是 Windows 的保護機制，它寧可先停下來，也不要讓錯誤繼續傷害系統和資料。藍屏畫面上的錯誤代碼，就是它留給我們的線索。

常見電腦藍屏代碼，先看懂方向

  • MEMORY_MANAGEMENT、PAGE_FAULT_IN_NONPAGED_AREA：多半和記憶體有關，記憶體老化、接觸不良，或驅動程式寫錯位置。
  • IRQL_NOT_LESS_OR_EQUAL、DRIVER_IRQL_NOT_LESS_OR_EQUAL：常見於驅動程式出問題，特別是剛更新或剛裝新硬體之後。
  • CRITICAL_PROCESS_DIED：系統關鍵程序停止，可能和系統檔案損壞或硬碟狀況有關。
  • INACCESSIBLE_BOOT_DEVICE：開機時找不到系統碟，硬碟故障或開機設定跑掉時常見。
  • WHEA_UNCORRECTABLE_ERROR：指向硬體層級錯誤（CPU、主機板、電源供應不穩），比較需要檢測儀器確認。
  • VIDEO_TDR_FAILURE：顯示卡或其驅動回應逾時，打遊戲、看影片時發生要往這個方向查。

提醒您：代碼只是方向，不是結論。同一串代碼可能有好幾種成因，最後還是要交叉檢測才能確定，千萬不要只看代碼就自己買零件來換。

藍屏照片先傳給我們看
把藍屏畫面拍下來傳 LINE，錯誤代碼一看就知道往哪個方向查。先免費評估、報價透明，確認後再預約維修，不會要您先重灌賭一把。

拍照免費評估

電腦藍屏自救檢查清單（由簡到難）

  1. 1. 把藍屏拍下來，代碼最重要。藍屏畫面下方有一串英文錯誤代碼（例如 MEMORY_MANAGEMENT），先用手機拍清楚再讓它重開。這串代碼就是電腦留給我們的「病歷」，有拍到，診斷速度差很多。
  2. 2. 回想藍屏前改了什麼。最近有沒有裝新軟體、更新驅動程式、Windows 剛更新完、或加了新硬體（記憶體、硬碟、顯示卡）？藍屏十之八九跟最近的變動有關，先把想到的記下來。
  3. 3. 拔掉所有外接裝置再開機。外接硬碟、USB 隨身碟、讀卡機、印表機先全拔，只留電源、螢幕、鍵盤滑鼠。能正常進桌面的話，再逐一插回，大概就能找到兇手。
  4. 4. 還能進桌面，第一件事先備份。把重要檔案（文件、照片、報告）先複製到外接硬碟或雲端，再慢慢查原因。千萬不要在藍屏頻繁的狀態下直接重灌系統，資料會先不見。
  5. 5. 記下藍屏發生的時機。都是在打遊戲、剪影片這種高負載時發生？可能是過熱或顯示卡、電源問題；一開機就藍、或隨機亂跳？比較像記憶體、硬碟或系統檔案問題。發生時機是判斷方向的重要線索。
  6. 6. 試試看安全模式。如果連桌面都進不去，連續強制關機重開 2～3 次，Windows 通常會進入修復環境，選「安全模式」啟動；安全模式進得去，代表多半是驅動或軟體問題，硬體故障的機會較低，先在安全模式裡把資料備份出來。

出現這些情況，就別再自己試了

  • 藍屏越來越頻繁，從偶爾一次變成每天、甚至開機就藍
  • 伴隨硬碟「喀喀」異音、檔案莫名損壞或消失——硬碟可能快壞了，請先停手保資料
  • 自己完全沒動任何設定就突然開始當機，多半是硬體（記憶體、硬碟、電源）出問題，需要檢測判斷，不要自行拆記憶體或電源供應器測試
  • 藍屏後連安全模式都進不去，或修復環境一直失敗

如果您的藍屏是在打遊戲、剪影片時才出現，也建議順手看一下過熱篇：高負載熱當機和藍屏常常是同一件事的兩種表現。我們的檢測會把記憶體、硬碟健康、溫度與系統紀錄一起交叉比對，找出真正的兇手再報價給您。

常見問題

電腦藍屏會自己好嗎？

偶爾一次的藍屏（例如剛好遇到系統更新出包）確實可能不再出現，可以先觀察。但如果一週內出現兩次以上、或頻率越來越高，就代表背後的原因還在，不會自己消失，建議盡快檢測，特別是硬碟和記憶體的問題越拖越傷資料。

藍屏是不是一定要重灌？

不一定。很多藍屏是驅動程式、單一軟體或硬體接觸不良造成的，處理好原因就不用重灌。只有系統檔案損壞嚴重、或確認是系統本身問題時，我們才會建議重灌，而且會先幫您把資料備份出來再進行。

藍屏照片傳 LINE 就可以先判斷嗎？

可以先給方向。錯誤代碼加上發生時機（例如打遊戲才藍、開機就藍），通常能先縮小到一兩個嫌疑零件，我們會回覆您初步判斷和檢測建議；要完全確認，還是需要實機跑檢測，這部分評估不收費，請放心傳。
